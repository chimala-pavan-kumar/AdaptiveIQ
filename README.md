# AdaptIQ – AI-Powered Adaptive Learning Platform

AdaptIQ is a web-based adaptive learning platform designed to provide students with a structured and personalized learning experience.

The platform allows students to explore courses, take assessments, view their performance, and continue learning based on the concepts they need to practice.

Note: The current version is a frontend-based prototype developed using HTML, CSS, and JavaScript. AI/ML-based personalization can be integrated in future versions.

---

## 📌 Project Overview

Traditional learning platforms provide the same learning content to every student.

AdaptIQ aims to provide a more personalized learning experience by following this flow:

Courses → Assessment → Results → Personalized Learning

Students can select a course, complete an assessment, view their score and concept analysis, and continue with structured learning content.

---

## 🎯 Problem Statement

Students have different learning speeds and different levels of understanding.

A traditional learning system may provide the same content to every student, making it difficult to identify which concepts require more practice.

AdaptIQ is designed to address this by providing:

- Course-based learning
- Online assessments
- Automatic score calculation
- Strong and weak concept identification
- Personalized feedback
- Progress tracking
- Structured learning content
